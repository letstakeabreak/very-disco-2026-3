# Descent transition video

`public/assets/video/descent.mp4` bridges the visual-novel intro into the live workbench.

- Generated by [make-descent.py](make-descent.py) (Pillow + ffmpeg/libx264): 720×1080, 30 fps, 6 s, yuv420p, CRF 27, `+faststart`, no audio track.
- Sources: the shipped plate `public/assets/textures/workshop-v4.webp`, and [game-first-frame.png](game-first-frame.png). That frame was captured from the running game at 720×1080 in its first state (energy core in the press) with the HUD hidden, so the last shot matches what the player sees next.
- Shot: porthole close-up with rising bubbles, lights flicker on while the camera pulls back to the whole workshop, a dip to dark, then the real first frame.
- No new generated imagery. Regenerate with `python3 assets/source/video/make-descent.py` after the plate or the first frame changes.
