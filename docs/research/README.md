## 현재 협업 기준

- 세 명 모두 개발한다: [letstakeabreak](https://github.com/letstakeabreak), [sy-Lee-01](https://github.com/sy-Lee-01), [magic3ightball](https://github.com/magic3ightball).
- 사용자가 PRD 작성과 기술 선택을 총괄 AI에 위임했다. 기존 **COMPACT BLOOM은 폐기됐다**. 새 개발 기준은 **DEEP PRESS**다. 위임에 따른 설계이며 기능·성능·배포 성공의 검증 결과는 아니다.
- 최신 [prd.md](../../prd.md), [instruction.md](../../instruction.md), [goal.md](../../goal.md)가 개발 명세·역할·convention·실행 목표를 정한다. 이 조사 안의 초기 후보와 A/B/C 전담안은 현재 역할을 대체하지 않는다.
- 사용자 에셋 요구는 **화려한 그래픽 / ImageGen 시각 에셋 / Meshy 7 flagship와 high-quality texture의 3D 에셋**이다. 대회 AI 정책은 별도 미확인으로 유지한다.
- [협업 GitHub](https://github.com/letstakeabreak/very-disco-2026-3) · [공유 Drive](https://drive.google.com/drive/folders/1xtekUGeYoumuf2wn8YIGpkEAt1_bvjEr). 링크 확인, 원격 게시, 파일 업로드, AI에 전달 완료는 서로 다른 상태다.

## 다른 AI에 전달하는 방법

1. 루트의 **prd.md + instruction.md + goal.md**, **[AI_UPLOAD_ALL_IN_ONE.md](AI_UPLOAD_ALL_IN_ONE.md)**, 최신 **[TEAM_STATE.md](TEAM_STATE.md)**를 전달한다. 합본은 조사 전체와 이관 시점 팀 상태를 담으며 루트 개발 문서의 최신본을 대신하지 않는다.
2. “최신 루트 문서와 컨텍스트에 따라 내 GitHub ID의 개발 범위를 수행하라. 사용자 요구, 현재 설계 결정, 공식 규정, 제안, 미확인, 실제 시험을 구분하라”고 입력한다.
3. 기준이 바뀌면 같은 새 버전과 최신 상태를 세 AI에 다시 전달한다. GitHub·Drive는 AI 대화 상태를 자동 동기화하지 않는다.
