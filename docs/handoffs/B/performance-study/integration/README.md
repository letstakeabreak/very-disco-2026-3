## 남은 범위

- 강제 context-loss 재시도 통과가 이전 iPhone의 자연 발생 GPU 시작 실패 원인을 해결했다는 뜻은 아니다. 실제 iPhone 재시도·3분 성능·touch/cancel·회전은 재검증이 필요하다.
- 복구 후 **점수와 용량**은 유지됐다. 보관물의 정확한 압축·손상 외형 복구는 계약 `1.0.0`에 저장된 `SpecimenState`가 없어 보장할 수 없다. A가 제안한 계약 변경으로 보관물 상태를 제공하면 B가 이를 읽도록 연결해야 한다. hidden global cache로 우회하지 않는다.
- 작은 화면의 overflow 통과는 아트 가독성 합격이 아니다. 320×568 캡처에서 C의 카드가 계기판과 케이스를 가린다. C와 작업 영역/HUD 배치를 조정하고 콘셉트와 다시 비교해야 한다. 이 검증에서 C 파일은 수정하지 않았다.
- main 머지, 배포, 게임잼 제출 또는 iPhone 검증을 수행한 기록이 아니다.
