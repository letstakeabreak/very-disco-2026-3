# v4 CEO 재플레이 (G22)

2026-09-26. [Goal v4](../../../goals/v4-ceo-review.md)의 마지막 항목이다. 첫 리뷰와 같은 방식으로 iOS 시뮬레이터(iPhone 18 Pro Max, Safari, `vite preview`)에서 두 판을 했다. 한 판은 처음 하는 유저, 한 판은 규칙을 아는 유저다. 오늘의 회수는 2026-09-26이고 만점은 1,325점이다.

## 두 판 결과

| 판 | 한 일 | 결과 |
|---|---|---|
| 1 처음 하는 유저 | 도입 6줄과 영상을 끝까지 봤다. 튜토리얼대로 코어를 골라 돌리고, 삐걱대기 전에 떼고 담았다. 렌즈는 일부러 끝까지 눌러 부쉈다. 카세트는 담았다. | 810점, 61%, C. 줄 합계(390+0+420)가 점수와 같다. |
| 2 규칙을 아는 유저 | 튜토리얼 없이 윤서의 부탁으로 시작했다. 렌즈는 살살, 카세트는 적당히 눌렀다. 코어는 공간이 모자라 한계까지 눌렀고, 관성 때문에 부서졌다. | 940점, 70%, C. |
| 참고 (headless) | 삐걱 0.15초 뒤에 떼는 사람 속도로 세 물건 모두 담았다. | 1,282점, 96%, A |

첫 리뷰에서는 1판 822점, 2판이 40초 만에 만점이었다. 이제는 두 판 모두 만점과 거리가 있고, 결과가 누른 방식에 따라 갈린다.

## 새로 보인 것

- **한계 근처의 미세 조절.** 0.89까지 누른 뒤 0.35초를 더 누르면 관성까지 +0.12라 바로 부서진다. 규칙대로지만, 한 번 더 조금만 누르려는 사람에겐 가혹할 수 있다. 누르는 동안 예상 부피는 보이므로 당장은 두고, 사용자 플레이 뒤에 증가율을 다시 볼 후보로 남긴다.
- **도현의 설명 포즈.** 슬픈 대사에서 배경은 어두워지지만 얼굴은 옅게 웃는다. ㉔와 같은 의존 항목이다.
- **소리.** 실제 iPhone에서 들어 보는 건 사용자 확인으로 남는다.
