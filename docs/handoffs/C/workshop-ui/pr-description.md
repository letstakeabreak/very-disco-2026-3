불투명 HUD가 사실적인 작업대와 따로 보이고, 첫 화면에 회수 목적이 없던 문제를 개선합니다. UI를 반투명 유리와 황동 계기판 색으로 통일하고 압력·위험에 따라 빛이 반응하게 했습니다. 시작에는 침몰한 연구소의 마지막 회수 지시를, 결과에는 실제 가져온 물건에 맞는 문구를 넣었습니다.

눈누에서 고른 에스코어드림과 리디바탕의 제작사 원본을 로컬 번들에 포함합니다. 글꼴을 변형하지 않았으며 이용 조건과 출처도 배포합니다. 조작부를 두 줄로 줄이고 짧은 세로 화면의 압력계·케이스 가림, 짧은 가로 화면의 도입부 잘림을 보완했습니다.

게임·대화상자 버튼은 높이48px와 모서리4px를 공유합니다. 선택지는 공통 트레이로 묶고, 압축/담기/버리기와 마치기는 간격·구분선으로 나눕니다. 그룹 내부8px보다 그룹 사이16px를 넓게 유지하며, 청록색 선택 표시와 황동색 실행 강조를 구별합니다. 작은 화면에서도 버튼을 축소하지 않습니다.

- 선행 PR #16 (`role/c-app-m1`, fb808714) 위의 후속 PR입니다. 해당 브랜치를 base로 두어 이번 UI 변경만 보이게 했습니다. #16 통합 후 `integration/v2`로 retarget할 수 있습니다. 공유 계약·코어·렌더러는 수정하지 않았습니다.
