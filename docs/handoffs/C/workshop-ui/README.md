# 작업대와 이어지는 HUD · 회수 도입부 · 글꼴

이 문서와 캡처는 최초 UI 개선 기록이다. 이후 버튼48px 통일·게슈탈트 그룹 배치·5화면 재검증은 [디자인 일관성 후속 기록](../design-consistency/README.md)에 보존했다. 현재 규격은 후속 기록을 따른다.

2026-09-25. 사용자가 HUD의 이질감, 첫 진입 맥락 부족, 눈누 글꼴 적용을 요청했다. 기존 B 담당 세션에서 이 요청에 필요한 C 앱 파일을 수정하도록 범위가 확장된 작업이다. 다른 팀원의 변경을 덮어쓰지 않도록 `role/c-app-m1`의 `fb808714b715db4b525c4af2d617c71d8146d437`에서 독립 브랜치 `feat/workshop-ui`를 만들었다. PRD·계약1.1.0을 유지한다.

## 달라진 경험

- 둥근 불투명 카드와 주황 버튼을 각진 반투명 유리·황동 가장자리로 통일했다. 배경의 청록색과 작업등 빛이 패널 뒤로 비친다. 압력에 따라 반사 위치가 움직이고 M1 긴장도 경고에서는 패널이 붉어진다. **CSS의 backdrop-filter·gradient·합성 효과**이며 별도의 WebGL HUD 셰이더를 추가한 것은 아니다. blur는 버튼마다 중복하지 않고 상단·상태·조작부 그룹에서 처리한다. 효과 미지원·투명도 감소 설정에는 더 불투명한 배경을 사용한다.
- 첫 진입은 PRD의 “침몰한 연구소의 마지막 회수 작업”을 소개한다. 플레이어 역할, 부품과 연구 기록의 의미, 1L 제한, 압축과 손상의 관계를 설명하고 한 번 누르면 기존 첫 물건 튜토리얼로 이어진다. 컷신·새 게임 규칙·타이머는 추가하지 않았다. 결과 문구는 실제 보관 목록에 따라 기록 회수·부품 회수·빈 케이스로 구분한다.
- 시작 안내 뒤의 HUD는 감추고 모달이 열린 동안 배경 조작부를 inert 처리한다. 게임 중 조작부는 두 줄로 줄였다. 짧은 세로 화면은 기존 고정 작업대의 중앙14–88%를 HUD와 버튼 사이에 맞춰 압력계·케이스를 보이게 한다. 이 수치는 현재 카메라 구성에 맞춘 앱 배치이며 렌더러 구도가 바뀌면 재확인해야 한다.
- 넓은 화면에서는 기존 ImageGen `workshop-v4.webp`를 흐린 주변 배경으로 재사용한다. 실제 WebGL 작업대는 중앙에 그대로 남는다. 가로로 짧은 화면은 도입부 제목과 지시서를 양옆에 놓아 잘림을 막는다.

## 글꼴 선정·출처

[눈누 에스코어드림](https://noonnu.cc/font_page/223)에서 찾은 직사각형 고딕을 계기판·버튼·영문 로고에 사용했다. [눈누 리디바탕](https://noonnu.cc/font_page/324)은 이야기와 결과 제목에 사용한다. 한글과 영문이 각각 다른 시스템 폰트로 나뉘던 기본값을 교체했다.

두 글꼴 모두 제작사에서 내려받은 원본 OTF다. 에스코어드림은 파일 수정 금지 조건에 따라 변환·서브셋·이름 변경을 하지 않았다. 제작사 저작권 안내 PNG와 리디바탕의 저작권·OFL1.1 전문을 배포 파일에 포함하고 첫 화면 “글꼴 출처”에서 열 수 있게 했다. [원본 다운로드·SHA256·바이트 기록](fonts.json), [에스코어 공식 조건](https://s-core.co.kr/company/font2/), [리디 공식 조건](https://ridicorp.com/ridibatang/).

모든 글꼴은 앱에 포함되어 외부 CDN 없이 로드된다. 글꼴 합계2,926,652bytes, 전체 빌드15,177,594bytes로20MB 예산 이내다. 사용자의 명시적인 눈누 글꼴 요청을 ImageGen 시각 에셋 원칙에 대한 이번 글꼴 예외로 기록한다. 새 외부 그림·재질 팩은 도입하지 않았다.

## 검증

- `npm run check`: 고정23파일, 타입,20모듈 경계,15파일100테스트, 빌드 통과. JS701.59kB의 Vite500kB 권고 경고는 남는다.
- `npm run ownership -- --role C --base fb808714b715db4b525c4af2d617c71d8146d437`, `git diff --check` 통과. 변경은 `src/app/**`와 이 C 검증 폴더에 한정한다.
- [실제 브라우저 보고서](report.json): desktop Chromium의390×844,320×568,1440×900,844×390. 글꼴3파일 로드, 시작 제목·버튼 잘림 없음, 문서 넘침 없음, 게임 조작 버튼 최소44px, 모달 배경 비활성화·해제 통과.
- 실제 마우스로 회전→내구 힌트→압축→담기→마치기를 실행했다. 카세트33% 압축 후440점·남은 공간0.44L, 기록을 회수한 결과 문구를 확인했다. 다시 시작해 렌즈 위험 경고·100% 파손·버리기·빈 케이스 결과를 확인했다. 일시 정지/계속과 의도적인 WebGL 오류→renderer 재시도/계속도 통과했다.
- [배포 빌드의 하위 경로 로드](package-report.json): 로컬 정적 서버의 `/package/`에서 모델4개·글꼴3파일 로드와 라이선스 링크2개 HTTP200을 확인했다. 글꼴/게임 에셋 요청은 모두 같은 하위 경로이며 실제 배포는 아니다. 정적 검사 서버에서 브라우저가 별도로 요청한 `/favicon.ico`는404였고 보고서에 구분해 남겼다.
- 오류0. 의도적인 `Context Lost` 로그는 재시도 검사의 입력이다. 소스13개 전후 해시와 실제 PNG15장을 보존했다. 캡처의 압력은 실제 시간이 흐르므로 바로 앞 JSON 상태와 조금 다를 수 있다.
