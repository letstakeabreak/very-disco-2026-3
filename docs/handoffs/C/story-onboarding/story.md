# DEEP PRESS — 도입과 귀환

사용자 요청 순서: 영문 워드마크 → 행동의 이유 → 캐릭터 포즈와 실제 이야기 흐름. 새 타이머·판정·아이템·음성은 추가하지 않는다. UI 서사만 확장한다. 연구원 **윤서**와 회수 기사 **도현**은 기존 여성/남성 캐릭터를 채택한 가상 인물이다. 플레이어는 둘에게 부품을 받아 프레스를 조작하는 회수 담당자다.

## 왜 이 물건이고, 왜 누르는가

침수된 연구소의 실험실에서 도현이 세 물건을 건져 밀폐된 작업실로 가져왔다. 에너지 코어는 장비의 전원, 광학 렌즈는 바다를 관찰하던 장치, 데이터 카세트는 연구 기록을 담고 있다. 큰 운반함은 침수되었고 수면으로 보낼 회수 캡슐에는1L 케이스만 들어간다. 세 물건의 원래 부피 합은2.20L다. 세 물건을 모두 원형 그대로 담을 수 없다.

프레스는 밖의 하우징·완충틀을 줄여 제한된 공간에 더 많은 가치를 남기는 장비다. 내부 코어·렌즈·기록까지 압착하면 가치가 손상된다. 이 설명은 실제 공학 주장이나 새 코어 규칙이 아니며 PRD의 기존 압축·손상 모델을 설명하는 허구적 배경이다.

## 도입 세 장면

1. 윤서 / **물속에 남은 연구소**: 침수된 실험실에서 도현이 세 부품을 건져 왔다. 이 안에 연구소가 남긴 전원·관측 장치·기록이 있다.
2. 도현 / **가져갈 수 있는 건1L**: 큰 운반함을 잃었다. 회수 캡슐에는 이 케이스 하나뿐이다. 부품별 의미를 보여 주고, 그대로 모두 가져갈 수 없음을 설명한다.
3. 도현 / **겉을 줄여, 안을 지켜요**: 외피와 완충틀을 눌러 부피를 줄인다. 돌려 살펴보고, 조금씩 눌렀다 떼고, 크기·가치를 비교해 담는다. 마지막 버튼에서 실제 게임을 시작한다.

각 장면은 사용자가 넘긴다. 이전으로 돌아갈 수 있고 즉시 회수를 시작할 수 있다. 자동 넘김·강제 타자 애니메이션은 없다. 재시작은 이야기 반복 없이 바로 플레이한다. 시작 화면과 정지 화면에서 이야기를 다시 볼 수 있다.

## 플레이 중 연결

선택한 물건의 용도는 짧은 한 줄로 HUD에 남는다. 첫 물건의 회전→압축→보관 안내는 동료의 말투로 이어진다. 누르는 동안에는 기존 압력·예상 크기·위험 피드백을 우선한다. 대화 때문에 압축 도중 입력을 끊지 않는다.

## 마지막 작업 뒤

마지막 압축 자체는 회수 완료가 아니다. 마지막 물건을 담기/버리기로 처리하거나 ‘마치기’를 선택해 코어가 `complete`를 내면, 결과표 앞에 짧은 귀환 장면을 보여 준다. 캡슐에 담기지 않은 물건은 회수했다고 말하지 않는다.

- 카세트 보관: 윤서가 기록의 귀환을 받아들인다. 손상이 있으면 온전하다고 말하지 않는다.
- 다른 부품만 보관: 도현이 회수한 부품을 확인한다. 연구 기록까지 가져왔다고 하지 않는다.
- 보관0개: 빈 케이스를 인정하고 다음 회수에서 조금씩 누르자고 말한다. 성공 표정·문구를 재사용하지 않는다.

실제 보관 목록은 이어지는 결과표에 그대로 보여 준다. 결과→다시 하기는 한 번의 버튼이다. 이야기 화면에서 배경 조작은 막고, 정지·렌더러 오류가 이야기를 덮은 경우에도 진행 위치를 보존한다.
