# 버튼 규격과 행동 그룹

2026-09-25. 사용자의 버튼 크기·디자인 일관성·게슈탈트 원리 적용 요청을 반영했다. 기존 UI PR #17의 후속 변경이며 시작 SHA는 `1ece4fd7043f65ce64e8aa006acc17c395eebd26`이다. PRD·계약1.1.0, C 소유 범위를 유지한다. 코드 판정·렌더러·공유 계약은 바꾸지 않았다. 최종 검사 소스는 [report.json](report.json)의 전후 SHA256으로 고정한다.

## 후속 개발에서도 유지할 규격

단위는 전부 **CSS px**다. 공통 값은 `src/app/style.css`의 토큰을 사용한다. 개별 화면에서 임의로 버튼을 줄이지 않는다.

| 항목 | 규격과 이유 |
|---|---|
| 게임·대화상자 버튼 | 최소48×48, 기본 높이48, 모서리4. 기본 크기에서 모든 검증 화면의 버튼 높이48을 실측했다. `min-height`이므로 글자 확대 시 필요한 높이는 늘어날 수 있다. |
| 같은 종류의 선택지 | 남은 물건 버튼은 같은 폭, 담기/버리기는 같은 폭, 대화상자 선택은 모두 같은 폭·높이. 중요도는 크기를 제각각 바꾸기보다 색·굵기·배치로 표현한다. |
| 화면 배치 간격 | 4/8/12/16/24 토큰. 물건 선택 트레이 안4, 같은 물건의 행동 사이8, 선택↔처리 및 처리↔종료 그룹 사이16. 테두리1과 글자 내부의 미세 간격은 별도다. |
| 상단 현황 | 두 수치 패널과 정지 버튼 높이48, 같은 위·아래 정렬선. 정지 버튼이 감춰져도 두 패널 폭은 유지한다. |
| 선택 상태 | 청록 테두리·배경과 ✓. 선택 표시를 압축 실행 버튼의 황동 강조와 구별한다. |
| 주 행동 | 압축/시작/계속하기는 황동색과 굵은 글자. 버튼을 누르는 동안 안쪽 그림자로 반응한다. |
| 보조·종료 행동 | 담기/버리기는 같은 물건 처리 그룹. 마치기는 더 큰 여백과 구분선 뒤에 놓고 차분한 색을 쓴다. 화면이 넓어 세로로 쌓일 때도 구분선과 간격을 유지한다. |
| 입력 상태 | hover는 테두리, pressed는 안쪽 그림자, 키보드 focus는 외곽선. disabled는 빛·그림자를 줄이고 실제 `disabled`로 실행을 막는다. 선택된 물건은 비활성 행동과 다른 상태다. |
| 이야기/결과 대화상자 | 본문에서 첫 행동까지24, 연속 선택 사이8. 좁고 짧은 시작 안내는 버튼 크기를 유지하면서 본문 간격을 줄인다. |
| 글꼴 출처 | 보조 펼침 대상은 높이32, 펼친 라이선스 링크는 최소 높이48. 게임 버튼과 정보 펼침은 다른 요소다. |

48px는 이 게임의 공통 조작 규격이며 네이티브 pt와 혼동하지 않는다. AAA 품질 인증이나 접근성 전체 준수 판정을 뜻하지 않는다.

## 게슈탈트 원리를 적용한 곳

- **근접성:** 현재 물건의 압축·보관·폐기는 가까이, 전체 회수 작업을 끝내는 마치기는 더 멀리 둔다. 반응형에서도 그룹 간격이 그룹 내부 간격보다 크다. [NN/G 근접성](https://www.nngroup.com/articles/gestalt-proximity/)
- **유사성:** 같은 선택 수준은 크기·모서리·서체·상태 표현을 공유한다. 서로 다른 의미의 선택 표시와 실행 강조는 색과 체크 표시로 구분한다. [NN/G 유사성](https://www.nngroup.com/articles/gestalt-similarity/)
- **공통 영역:** 회수물 선택지를 하나의 트레이 안에 넣어 하나의 선택 집합으로 읽히게 한다. 시각 그룹은 DOM의 이름 있는 `role="group"`과도 대응한다. [NN/G 공통 영역](https://www.nngroup.com/articles/common-region/)

이는 설계 원리를 적용한 판단이다. 실제 이용자 실험으로 오조작 감소나 이해도 상승을 측정한 것은 아니다.
